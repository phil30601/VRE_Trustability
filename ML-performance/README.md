# 3E-to-2E
Repo for collaborative battery ML project focusing on using 3-electrode data to predict 2-electrode data


Follow these steps for the notebooks:

1. Use Feature_Engineering.ipynb to extract the datasets and create the feature dataframes, which are saved in the Features folder
2. Use Model_Performance_3_10 to perform feature selection and develop ML models (baseline and ensemble models implemented). Model_Performacne_3_10_gp contains code for gaussian process regression model training/testing.
